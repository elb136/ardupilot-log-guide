# ArduPilot Log Field Guide

How to read ArduCopter DataFlash (.BIN) logs: triage order, ERR codes, and the common failure modes (vibration, notch/FFT, PID tuning, crashes, motors, battery, board power, compass, GPS, EKF, altitude hold, Loiter, optical flow, RC failsafe, CPU/logging). Each section lists the fields to plot, problem vs healthy example graphs, how to react, and the parameters involved.

Live page: https://elb136.github.io/ardupilot-log-guide/

Graphs use synthetic data shaped like real logs. Parameter names follow Copter 4.5/4.6; check against your firmware version.
